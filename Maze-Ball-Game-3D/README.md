# Maze Ball Game (3D)

A simple 3D game made with Unity and C#, in which the player rolls a ball through a maze.

## Features

- Physics-based ball movement
- A camera that follows the ball

## Controls

| Action | Key |
|---|---|
| Roll the ball | Arrow keys / W, A, S, D |

## Built With

Unity 2021.1.7f1, C#
