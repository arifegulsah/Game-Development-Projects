# Random Labyrinth Generator (3D)

A 3D maze game made with Unity and C#. A new random labyrinth is generated every time and the player tries to find the way out.

## Features

- Random maze generation with a depth-first search (backtracking) algorithm
- Adjustable maze size, from 5x5 up to 100x100 cells
- Generating the 3D maze walls from the maze data
- Player movement with Unity's Input System
- Teleport points and moving to the next scene
- Sound effects with an audio manager

## Built With

Unity 2021.1.7f1, C#
