# Dungeon Gunner (2D)

A top-down 2D dungeon shooter made with Unity and C#. The project is still in progress.

## Features

- Procedurally generated dungeon levels built from room templates
- A custom node graph editor for designing the room layout of each level
- Player movement and animations
- Aiming the weapon towards the mouse
- Camera that follows the player with Cinemachine

Art assets in `Assets/CourseAssets` come from the course material used while building the game.

## Built With

Unity 2021.1.7f1, C#
