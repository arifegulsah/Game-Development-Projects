# Race Game (3D)

A 3D car racing game made with Unity and C#. The player races against AI-controlled cars on a track.

## Features

- Car physics with acceleration, reversing and steering
- AI opponent cars that drive along the track by following checkpoints
- Checkpoint and lap system managed by a race manager
- Race UI
- Switching between camera views
- Sound effects on collisions

Track and car assets in `Assets/Imports/_Udemy Racer Assets` come from a Udemy course asset pack.

## Controls

| Action | Key |
|---|---|
| Accelerate / reverse | Up / Down arrow keys or W, S |
| Steer | Left / Right arrow keys or A, D |
| Switch camera | Space |

## Built With

Unity 2021.1.7f1, C#
