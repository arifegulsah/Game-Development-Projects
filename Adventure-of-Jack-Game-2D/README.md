# Adventure of Jack (2D)

A 2D platformer game made with Unity and C#. The player guides Jack through three levels full of enemies, traps and characters to talk to.

## Features

- Main menu, pause menu, settings menu, outro and credits scenes
- 3 levels with checkpoints and death zones
- Running, jumping and climbing ladders
- Enemies that patrol the level, with weak spots to defeat them
- Health bar, healing power-ups and poison
- Chests, collectible items and an inventory
- Dialogues with in-game characters
- Background music and sound effects

## Controls

| Action | Key |
|---|---|
| Move | Arrow keys / A, D |
| Jump | Space |
| Climb ladders | Arrow keys / W, S |

## Built With

Unity 2020.3.32f1, C#
