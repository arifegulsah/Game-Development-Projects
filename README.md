# Game Development Projects

A collection of the games I have made with **Unity** and **C#**, from 2D platformers to 3D racing. Each game lives in its own folder as a separate Unity project.

| [Dungeon Gunner](Dungeon-Gunner-Game-2D) | 2D top-down shooter | Procedural dungeon generation, node graph editor | Jan 2023 – Sep 2024 |
| [Maze Ball Game](Maze-Ball-Game-3D) | 3D maze | Physics-based ball movement | Oct 2023 |
| [Random Labyrinth Generator](Random-Labyrinth-Generator-3D) | 3D maze | Random maze generation with depth-first search | Oct 2023 – Nov 2023 |
| [Race Game](Race-Game-3D) | 3D racing | AI opponent cars, checkpoints and laps | Jan 2024 |

## Opening a Project

1. Open **Unity Hub** and click **Add** (or **Open**).
2. Select the folder of the game you want to open, for example `Race-Game-3D`.
3. Open it with the Unity version written in that game's README.

Unity's generated folders such as `Library` are not included in this repository. Unity creates them again automatically the first time a project is opened, so the first launch may take a little longer.
